PrepAI is an AI-powered mock interview and career preparation platform designed to help students and job seekers practice realistic technical, behavioral, HR, and role-specific interviews. The system uses Large Language Models (LLMs) to dynamically generate personalized interview questions based on the candidate's target role, skills, experience level, job description, and resume.

The platform provides both text-based and voice-based interview modes, allowing users to interact with an AI interviewer in a realistic interview environment. During the interview, the system analyzes the candidate's responses and can dynamically generate follow-up questions based on the quality and context of previous answers.

After completion, the AI evaluates the interview using multiple dimensions such as technical knowledge, communication, clarity, confidence, problem-solving ability, and relevance of responses. It generates a detailed performance report containing an overall score, strengths, weaknesses, areas requiring improvement, and personalized recommendations.

The platform also maintains interview history and performance analytics so users can track their progress over multiple sessions. Resume and job-description analysis can be used to generate highly personalized interview questions relevant to the candidate's background and target position.

The system will be developed using React and Tailwind CSS for the frontend, Python FastAPI for the backend, MongoDB for data storage, Google Gemini for LLM-based question generation and evaluation, and an open-source/realtime voice technology such as LiveKit for voice-based interviews.
